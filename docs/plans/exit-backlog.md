# Exit backlog — what people want to leave

Prioritized population queue for `data/exits/`. Criteria: how many people are
actually trying to leave it (search demand, cultural moment), how good our
sources are for it (enrichment + alternatives), and category spread — the site's
thesis is that *any* dependency is exitable, so the list must never read as
just "big tech alternatives".

Live exits already: whatsapp, instagram, netflix, spotify, google-photos,
chatgpt, claude, gemini, doomscrolling, smoking, toxic-relationship,
oppressive-regime, supermarket-herbs.
