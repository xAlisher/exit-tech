Exit Google Docs

You don't have a file. You have a link.

// why

  • Nothing lives on your disk — your work is a link, and the link's owner isn't you.
  • Export never round-trips: download to .docx or .odt and the comments, suggestions, and edit history stay behind.
  • Terms of service rated “D” — see the documented points at ToS;DR

// first, get your stuff out

  1. File → Download keeps a local copy (.docx, .odt, or PDF) — do it per document for the ones you care about.
  2. For everything at once, use takeout.google.com — select Drive and set the Docs format to .docx or .odt.

// exit paths

[self-host] Self-host a collaborative editor

CryptPad

End-to-end encrypted and account-free — the right pick when the document's privacy matters most; the editor is lighter than Google's.

via privacy-guides awesome-privacy awesome-selfhosted switching-software
Nextcloud + Collabora Online

The fullest Drive-plus-Office replacement with real-time co-editing — but someone has to run and maintain the server.

via awesome-privacy awesome-selfhosted switching-software
Etherpad

A dead-simple shared pad — paste a link and write together. Great for quick collaboration, not for formatted documents or spreadsheets.

via awesome-selfhosted switching-software

[switch] Own your keys, not just an account

dDocs (Fileverse) open source

Documents keyed to you instead of an account — encrypted and peer-to-peer. The most sovereign option, but the wallet-based setup is a wall if you're not in crypto, and losing your keys loses your docs.

via web3privacy

[switch] Go local — own the files, drop the cloud

LibreOffice

If real-time collaboration isn't what you actually need, this owns the files outright on your disk — no cloud, no link. You lose live co-editing.

via european-alternatives
Obsidian audited

For solo writing and notes meant to outlive any app — local Markdown files you keep forever. Not a fit if co-authoring is your core need.

via awesome-privacy
