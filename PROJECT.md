# exit.tech — Project Context

## Tagline
**Exit as culture.**

## Concept
exit.tech is a social network for logging exits from dependencies.
You build your profile not by what you have — but by what you've *left*.

Dependencies can be anything:
- Digital platforms (Google, Spotify, Instagram, iPhone)
- Financial (mortgage, credit cards, big banks)
- Relational (toxic dynamics, codependency)
- Institutional (corporations, mainstream media)
- Substance-based
- Anything else...

## Core mechanic
When you post an exit you log:
- **What** — the dependency you left
- **Why** — short personal note
- **Alternative** — what replaced it (or "nothing, and that's the point")
- **When** — year/month
- **Category** — digital / financial / relational / institutional / substance

## Social layer
- See how many others exited the same thing ("847 people also exited this")
- Tap to see who — if they made their exit public
- Follow people or follow exit categories
- Comment on exit posts
- "Almost out" — soft pre-exit state before committing
- Exit overlap on profiles — "you both exited 4 things"
- Exit momentum — trending exits this month
- Privacy controls per post — public / community / private

## Visual identity
- Wordmark: **~~EXIT~~** — the name strikes itself through
- Dark, stark, monospace — IBM Plex Mono
- Accent: #e8ff3e (acid yellow)
- Strikethrough is the core UI motif — exited things appear struck through
- X-simple layout — content first, no noise

## Viral mechanics
- Shareable exit card — dark, minimal, your exit + strikethrough, share to X/Farcaster/Nostr
- Anniversary reminders — "2 years since you exited Facebook" — reshare moment
- Exit streak counter on profile — "23 exits" as a sovereignty flex
- Exit challenges — monthly community campaigns
- Farcaster frame — log exit without leaving the feed
- "Almost out" counter — "2,400 people are thinking about leaving Instagram"
